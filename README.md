# 🔐 Encrypt App

A modern web application to securely hash text using **bcrypt**, built with a full-stack monorepo architecture.

---

## 🚀 Features

- 🔐 Encrypt text using bcrypt
- ✨ Smooth UI animations (Framer Motion)
- 🧊 Modern glassmorphism design
- 📱 Fully responsive (mobile + desktop)
- 🧠 Developer mode with hash breakdown:
  - Version
  - Cost (rounds)
  - Salt
  - Hash
- 📋 Copy to clipboard functionality
- 💡 Educational panel explaining hashing

---

## 🧩 Tech Stack

### Frontend
- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion

### Backend
- Node.js
- Express
- bcrypt

---

## 📂 Project Structure (Monorepo)

/frontend → React app (UI)
/backend → Express API (bcrypt hashing)
